## Layer choice — every unit is a browser walk

`## CHECK SURFACES` puts `ui-state` in "the rendered DOM in a real, attached, VISIBLE browser tab".
`custom` on this flow always names IndexedDB, localStorage, decoded image bytes or the serialiser's
output — none of which exist outside a browser, and each is "drive the real path and inspect the
state it left behind". `api-call` and `file-exists` both hang off a send driven from the restored
composer. So all 58 land in Playwright `.e2e.ts` under `packages/web/src/flows/quest-chat/`.

Journey, not matrix: `## WALK PATHS` lists 12 routes, so one test per route, each driven end to end.

## Groups — one per round, never two browser walks at once

Playwright writes one report path per package and every spec here is `web`, so each group ships
alone.
