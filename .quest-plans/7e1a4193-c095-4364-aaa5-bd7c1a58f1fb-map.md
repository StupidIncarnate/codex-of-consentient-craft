TRAPS
  Statics may import ONLY statics — so the three brands the spec names for the config (TickIntervalMs, ThresholdSeconds, ThresholdMinutes) cannot exist. Plain `as const` numbers, like every other statics file here. Spec change at step 8.
  Statics forbid root primitives — nest under `refresh` and `thresholds`.
  Transformers and statics forbid ad-hoc types: every type comes from contracts/, never a local interface.
  A transformer must `parse` its output through a contract. Raw object returns fail lint.
  `formatResetDurationTransformer` already exists and formats `2h5m`. It is a DIFFERENT output shape (days band, `0m`, no `<1m`) and transformers get one file per shape. Do not extend it, do not delete it.
  Tests import `.stub.ts`, never a contract TYPE. Importing a contract VALUE for `.options` in an `it.each` list is explicitly sanctioned.
  Never `git -C <path> …` — you are already in the worktree, call git bare.
  Never chain a git call with `&&` and never pipe it to head/tail/wc/sort — the whole command is refused. Use git's own `-n`, `--oneline`, `--stat`, `--name-only`.
