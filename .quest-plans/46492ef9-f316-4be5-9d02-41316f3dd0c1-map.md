    `.nullable()` (always present, may be null). `timestamp` is common to every member; `durationMs`
    lives only on the `task_notification` variant, so reaching it means narrowing on `type`.
  `durationMs` on shared's task_notification variant is branded `DurationMs`. The new contract brands
    its own field `TaskNotificationDurationMs`. Re-parse through the contract; never `as unknown as`.
  exactOptionalPropertyTypes is on: omit an optional property, never pass `undefined`. The repo idiom
    is `{...(x === undefined ? {} : { x })}` — the file you are editing already uses it.
  No new threshold numbers anywhere. 60 seconds and 60 minutes live in `elapsedDisplayConfigStatics`
    and reach you through `durationDisplayTransformer`.
  `elapsedPartsTransformer` already floors a negative gap at zero (`Math.max(..., 0)`), so a
    backwards timestamp pair lands on `<1m` with no extra branch.
  Two git forms come back refused whatever you ask of them, and each has a plain substitute:

    (2) Never chain a git call with `&&` and never pipe its output. Trim with git's own flags
        (`-n <count>`, `--oneline`, `--stat`, `--name-only`), one git call per invocation.
