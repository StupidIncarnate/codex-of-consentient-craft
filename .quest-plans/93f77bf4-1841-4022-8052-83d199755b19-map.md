chain is `SessionViewWidget` -> `ChatPanelWidget` (readOnly) -> `ChatEntryListWidget` ->

make a unit pass, that is a finding to report, not a change to make quietly.

TRAPS
  The duration test id is `subagent-chain-duration`, lower-case with hyphens — NOT the SCREAMING_SNAKE
    the sibling elements in these widgets use. The quest pins that exact string.
  `ChatPanelWidget` takes NO `now` prop, and must not gain one. The whole session-view rule is that
    no clock reaches a chain here.
  A chain is built from ENTRIES by `collectSubagentChainsTransformer`, which ALWAYS sets
    `taskToolUse` to the Task entry — it can never be null. So a `taskToolUse: null` chain is only
    reachable by handing `SubagentChainGroupStub({ taskToolUse: null })` straight to
    `SubagentChainWidget`, never from a panel or route test.
  A chain needs a `Task` tool_use (`toolName: 'Task'`) plus at least one entry carrying the SAME
    `agentId` AND `source: 'subagent'` — `indexSubagentEntriesTransformer` buckets only on those two
    together. A Task with no sub-agent lines makes a chain with `entryCount: 0`, which still renders.
  Nesting is by `parentAgentId` on the INNER Task entry, matching the outer Task's `agentId`, and the
    outer Task must come FIRST in the array. Mirror
    `packages/web/src/transformers/collect-subagent-chains/collect-subagent-chains-transformer.test.ts`
    around lines 600-660 and 720-815.
  `useElapsedTickBindingProxy().getTickIntervalCount()` counts ONLY a `setInterval(fn, 60000)` —
    `elapsedDisplayConfigStatics.refresh.tickMs`. The raccoon sprite's own interval is 2000 / 500 /
    300 ms (`raccoonAnimationConfigStatics`) and passes straight through, so it never folds into that
    count. Do NOT assert "zero setInterval calls" globally; the raccoon makes that false.
  That same proxy stages `Date.now` to a fixed instant for every call in the test. Create it inside
    the ONE test that needs the count, never inside `ChatPanelWidgetProxy` — staging it there would
    pin `Date.now` for every chat-panel and session-view test in the package.
  exactOptionalPropertyTypes is on: omit an optional prop, never pass `undefined`. The idiom in these
    files is `{...(x === undefined ? {} : { x })}`.
  Proxies expose SEMANTIC methods and never hand back a child proxy. A test must not chain through
    two proxy levels; each level adds its own one-line delegation.
  Two git forms come back refused whatever you ask of them, and each has a plain substitute:
    (1) Drop `-C` — you already sit inside the worktree, so call git bare from where you stand.
    (2) Never chain a git call with `&&` and never pipe its output. Trim with git's own flags
        (`-n <count>`, `--oneline`, `--stat`, `--name-only`), one git call per invocation.
