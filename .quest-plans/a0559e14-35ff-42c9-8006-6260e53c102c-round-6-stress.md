   elapsed time. Wrong behavior this would catch: if `use-elapsed-tick-binding.ts`'s cleanup does not

   or three intervals are now live and the visible figure jumps by more than one tick per real 60s, or
   causes multiple redundant state updates in the same window. Surface: `use-elapsed-tick-binding.ts`

   unmounts the owning widget repeatedly and asserts the number of live timers.

   Wrong behavior this would catch: an off-by-one-tick value if some part of the calculation anchors to
   a value captured before the reload rather than recomputing from scratch on the new mount. Surface:
   `execution-row-layer-widget.tsx` / `elapsed-parts-transformer.ts`'s use of the current-time input on
   a fresh mount.

   waiting for a tick) holds on a cold deep-link entry exactly as it does after in-app navigation, and
