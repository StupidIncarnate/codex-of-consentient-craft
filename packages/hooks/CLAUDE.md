# Hooks Package - Claude Session Guide

## Never Edit `.claude/settings.json` Directly

Hook entries in `.claude/settings.json` (`PreToolUse`, `SessionStart`, `SubagentStart`, `WorktreeCreate`, etc.) are
generated by `dungeonmasterHooksCreatorTransformer` and written by `InstallCreateSettingsResponder`.

To add/change a hook, edit the transformer (and matcher/command definitions) — **do NOT hand-edit
`.claude/settings.json`**. See root `CLAUDE.md` ("Never Edit `.claude/settings.json` Directly") for the
build → `npm link --workspaces` → `npm run init` flow that regenerates settings for this repo.

## SubagentStop: `transcript_path` is the PARENT session, not the sub-agent's

For the `SubagentStop` event, `transcript_path` points at the **parent/main-session** transcript. The
stopping sub-agent's OWN transcript is a separate, **undocumented** field: `agent_transcript_path`
(`.../<session>/subagents/agent-<id>.jsonl`). A hook that reads `transcript_path` inspects the wrong
conversation. Read `agent_transcript_path`, falling back to `transcript_path` only when absent.

Other fields present on the real event (established empirically — the Claude Code docs list none of
this): `agent_id`, `agent_type`, `stop_hook_active`, `last_assistant_message`, `permission_mode`,
`effort`, `background_tasks`.

The block discriminator is `get-agent-prompt` **carrying a `workItemId`**: work-item agents pass one
and must signal back; minions pass none, legitimately never signal, and are therefore exempt.
`stop_hook_active` means the nudge already fired once — allow the stop and let the orchestrator's
orphan-recovery backstop take it.
